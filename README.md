# Giftcard · จับฉลากของขวัญ (หลายห้อง)

ใครก็สร้างห้องของตัวเองได้ ผู้จัดไม่ต้องล็อกอิน ผู้เล่นเปิดการ์ดของตัวเองบนมือถือพร้อมกัน

## วิธีทำงาน
- หน้าแรก `/` : สร้างห้อง (ใส่แค่ชื่องาน) ได้ **รหัสห้อง 6 ตัว** กับ **ลิงก์ผู้จัด** และแสดงจำนวนห้องที่เคยสร้างทั้งหมด
- ผู้เล่น `/r/รหัสห้อง` : หน้าเดียว เห็นชื่องาน จำนวนของขวัญ และค้นหาชื่อคนที่ลงทะเบียนแล้วได้ ลงทะเบียนด้วยชื่อ + ของขวัญ (ไม่ระบุได้ จะเป็นกล่องปริศนา ?) 1 เครื่อง = 1 คน = 1 ของขวัญ
- ทุกคนในห้องลบของขวัญได้ทั้งของตัวเองและของคนอื่น (ถามย้ำ 2 ขั้น) เฉพาะก่อนจับฉลาก ใครก็กดเริ่มจับฉลากได้ (ถามย้ำ 2 ขั้น)
- หลังจับฉลาก: อนิเมชันกล่องจากชั้นวางเข้ารถเลื่อนซานต้า บินแจก แล้วหน้าห้องแสดงกล่องทุกใบ ค้นหาชื่อได้ ชื่อผู้ให้ของขวัญเห็นเฉพาะกล่องที่เปิดแล้ว
- ผู้จัด `/host/รหัสห้อง#k=รหัสลับ` : เปิดหน้าห้องเดียวกับผู้เล่น (rewrite ไป room.html) แต่มีปุ่มตั้งค่าห้อง จัดการรายชื่อ และเริ่มจับฉลากได้ แม้ยังไม่ได้ลงทะเบียน
- เครื่องผูกกับชื่อด้วย Supabase anonymous session ถ้าเปลี่ยนเครื่อง ผู้จัดกด "ปลดเครื่อง" แล้วเจ้าของเลือกชื่อตัวเองเข้าใหม่
- ภาพของขวัญเป็นไอคอนแบบแบน เลือกตามคำในชื่อของขวัญ (ไม่มีค่า AI)
- รหัสลับผู้จัดแสดงครั้งเดียวตอนสร้างห้อง เก็บเฉพาะแฮชในฐานข้อมูล **กู้คืนไม่ได้** ลิงก์ถูกจำไว้ในเบราว์เซอร์ที่สร้างห้องด้วย
- ห้องและข้อมูลทั้งหมดถูกลบอัตโนมัติหลัง 30 วัน (Vercel Cron วันละครั้ง)
- จำกัด: สร้างห้องได้ 5 ห้อง/ชั่วโมง/IP, ห้องละไม่เกิน 300 คน, ทั้งระบบไม่เกิน 5,000 ห้อง
- ดึงข้อมูลทุก 10 วินาที (หยุดเมื่อซ่อนแท็บ) และ cache `/api/room` ที่ CDN 5 วินาที เพื่อประหยัด CPU ของ Vercel

## ติดตั้ง
1. Supabase: สร้างโปรเจกต์ > SQL Editor > วางไฟล์ `supabase/schema.sql` > Run
   (ถ้าเคยรัน schema เวอร์ชันก่อนหน้าไว้แล้ว ให้รัน `supabase/migrate-v3.sql` แทน: ล้างข้อมูลผู้เล่นและผลจับฉลากเก่า แต่ห้องยังอยู่)
2. Supabase > Authentication > Providers: เปิด **Anonymous sign-ins**
3. Vercel: Import โปรเจกต์ (Framework: Other) แล้วตั้ง Environment Variables ตาม `.env.example`
   `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `CRON_SECRET`
4. Deploy แล้วทดสอบ: สร้างห้อง > เปิดลิงก์ผู้เล่นด้วยมือถือ 2-3 เครื่อง > กดเริ่มจับคู่ที่หน้าผู้จัด

## เช็คลิสต์ทดสอบ
- เปิดลิงก์ `/r/รหัส` และ `/host/รหัส` ตรงๆ แล้วไม่ขึ้น 404 (ใช้ rewrites ใน `vercel.json`)
- รหัสเดียวกันบนเครื่องที่สอง ต้องขึ้นว่าถูกใช้แล้ว จนกว่าผู้จัดกดรีเซ็ต
- ผู้เล่นเห็นเฉพาะการ์ดของตัวเอง (RLS) ผู้จัดเห็นทั้งหมดผ่าน API
- Vercel > Settings > Cron Jobs เห็น `/api/cron/cleanup`

## ข้อควรรู้ก่อนเปิดให้คนนอกใช้
- ผู้จัดเก็บข้อมูลส่วนบุคคลของผู้เล่น (ชื่อ รหัส) ควรมีหน้านโยบายความเป็นส่วนตัวและข้อกำหนดการใช้งานตาม PDPA
- Supabase แพ็กเกจฟรีจะหยุดโปรเจกต์ถ้าไม่มีการใช้งานนาน และมีโควตาจำกัด ถ้าเปิดสาธารณะควรดูแพ็กเกจที่เหมาะสม
- ชื่อ "Giftcard" ยังไม่ได้ตรวจเครื่องหมายการค้า/โดเมน
- ยังไม่ได้ทดสอบกับ Supabase/Vercel จริง ทดสอบเฉพาะหน้าเว็บ (ข้อมูลจำลอง) และตรรกะฝั่งเซิร์ฟเวอร์
